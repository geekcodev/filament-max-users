# v1.1.1 — порядок и полный состав колонок «Max пользователи» и «Max чаты»

Визуальные правки обоих разделов без изменения публичного API: порядок колонок в списках и полей на страницах просмотра
задан явно, все колонки списков стали переключаемыми, русская подпись `username` стала «Никнейм». Релиз patch-уровня —
ключи конфига, сигнатуры и значения по умолчанию config не менялись, изменились только значения подписей,
состав/видимость колонок и порядок полей.

### Новое

- Список «Max пользователи»: колонки идут в порядке `user_id`, `is_bot` (badge «Бот»/«Пользователь»), аватар, имя,
  фамилия, телефон (иконка по `phone_verified_at`), счётчик чатов (`counts('chatLinks')`). Фамилия теперь видима по
  умолчанию.
- Список «Max чаты»: колонки идут в порядке `chat_id`, `chat_type` (badge), `status` (badge), название (`displayName` —
  title / имя собеседника / `chat_id`), счётчик участников (`counts('chatUsers')`), последняя активность.
- Все колонки обоих списков переключаются тулбаром колонок. Помимо перечисленных, в составе есть и скрыты по умолчанию:
  у пользователей `full_avatar_url`, `name` (поиск/сортировка), `description`, `phone_verified_at`,
  `username`, `email`, `last_activity_time`, `profile_checked_at`; у чатов `icon_url`, `title` («Название из MAX»),
  `description`, `link` (кликабельная ссылка), `chat_checked_at`.
- Страница профиля пользователя: infolist перестроен в порядок `user_id` → `is_bot` → аватар → `username` → имя →
  фамилия → отображаемое имя → описание → телефон → `phone_verified_at` → `email` → `last_activity_time` →
  `profile_checked_at`, затем счётчик и список чатов.
- Страница чата: infolist перестроен в порядок `chat_id` → иконка → тип → статус → название → описание → ссылка →
  последняя активность → метаданные обновлены, затем участники; сырые `title` («Название из MAX») со страницы убраны
  (дублируют `displayName` у групп и каналов, пусты у диалогов), в списке осталась скрытой колонкой.
- Действие «Обновить из MAX» у чатов больше не падает на группах: реальный `GET /chats/{id}` отдаёт участников картой
  `{user_id: активность}`, фикс в `geekcodev/max-php-client` 1.1.9 (vendor обновлён), добавлен регресс-тест
  `test_refresh_metadata_action_parses_group_participants_map`.
- Зависимость `filament/filament` поднята 5.7.8 → 5.9.0 (advisory CVE-2026-104181, constraint `^5.0` не менялся).
- Ссылка чата (`link`) рендерится в href только для http/https-адресов: значение из MAX API проходит через
  `ChatPresenter::safeUrl()`, поэтому `javascript:`/`data:` не попадают в ссылку (A03); логика покрыта unit-тестами.
- Порядок и полный toggleable-состав закреплены feature-тестами: на каждый раздел — порядок колонок списка
  (`test_list_shows_columns_in_expected_default_order`), полный переключаемый состав
  (`test_list_exposes_every_column_as_toggleable`) и порядок полей страницы просмотра
  (`test_view_page_shows_entries_in_expected_order`) — регрессия по расстановке или видимости колонок ловится тестом.

### Изменение (BC)

- Значения строк `table.username` и `view.username` в `lang/ru` изменены с «Username» на «Никнейм»; `lang/en`
  осталось «Username». Ключи перевода прежние.
- Видимость колонок по умолчанию: в списках видны только перечисленные выше колонки, остальные скрыты и включаются
  переключателем колонок (состояние Filament хранит на пользователя). Подпись `is_bot` не изменилась («Бот»/«Bot»).
- Удалён дублирующий ключ `view.title` в секции `view` файлов `lang/{ru,en}/chats.php`: в массиве было два
  `title`, и эффективным всегда оставался второй («Название из MAX»/«Name from MAX»), поэтому поведение вызовов
  `__('...chats.view.title')` не изменилось; рабочие ключи `chats.table.title` и секция `chats.title.*`
  сохранены.
- Добавлены новые ключи перевода (additive, обратная совместимость сохранена): `users.table.name`,
  `users.table.description`, `users.table.full_avatar_url`, `users.table.phone_verified_at`,
  `chats.table.description`, `chats.table.link` — присутствуют и в `lang/ru`, и в `lang/en`.
- Публичный API не затронут: сигнатуры, ключи конфига, ключи lang-строк (кроме удалённого мёртвого дубля) и значения по
  умолчанию config совместимы с patch-релизом.

### Затронутые сценарии

- Просмотр списка «Max пользователи»: новый порядок колонок; скрытые поля, включая новые (`name`, `description`,
  `full_avatar_url`, `phone_verified_at`), включаются тулбаром колонок.
- Просмотр профиля пользователя: поля идут в заданном порядке, блок чатов остался последним.
- Просмотр списка «Max чаты» и страницы чата: новый порядок колонок и полей; «Название из MAX» доступно только как
  скрытая колонка списка; у ссылки чата в href попадают только http/https-адреса, некорректные значения не кликабельны.
- Обновление метаданных чата кнопкой «Обновить из MAX»: на группах и каналах с картой участников работает (фиксируется
  регресс-тестом); ошибки API показываются пользователю и логируются как раньше.
- Права доступа (`users.*`, `chats.*`), конфигурация, удаление записей чатов и обновление профилей — без изменений.
- Локализация: ключи `lang/ru` и `lang/en` синхронизированы, различаются только тексты у `username`.
